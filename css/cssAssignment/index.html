language I Know

HTML and CSS are the core foundational technologies used to build websites. HTML provides the raw structure and content of a page, while CSS handles the visual presentation and layout. They work together to turn raw data into readable, stylized web documents.

CSS (Cascading Style Sheets) is a foundational stylesheet language used to control the presentation, layout, and visual formatting of web documents written in HTML or XML. While HTML builds the basic structural skeleton of a website, CSS provides the visual facade, including colors, fonts, spacing, and responsive layouts
